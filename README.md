# DataAnalystPortfolioProject_PBI_SQL_Python_MarketingAnalytics
**Marketing Analytics Project**

This project uses SQL, Python, and Power BI to analyze customer journeys, engagement, products, and reviews. It brings the data together in an interactive dashboard to support marketing decisions.

**Tools and files**

- **SQL:** Prepare customer, product, journey, engagement, and review data.
- **Python:** Enrich customer reviews.
- **Power BI:** Visualize the data in `Episode 4 - Dashboard.pbix`.
- **PowerPoint:** Present the analysis and findings.

**Getting started**

1. Review and run the SQL scripts against the project database.
2. Explore the Python review enrichment script and its CSV output.
3. Open the dashboard file in Power BI Desktop and configure the data connections if needed.
